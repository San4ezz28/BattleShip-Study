# План проекта «Морской бой»

Отмечай пункты по мере выполнения: замени `[ ]` на `[x]` и закоммить.

## Как работать

Каждый этап заканчивается **работающей программой** и коммитом в git. Для этапа есть карточка
в [docs/stages/](stages/) с целью, ссылками на уроки, мини-шагами, заготовкой кода,
подсказками и самопроверкой.

Цикл на каждом шаге:

1. Прочитать урок и **набрать пример руками** (не копировать).
2. Написать свой шаг → собрать (`F7`) → запустить.
3. Не работает → прочитать текст ошибки компилятора (обычно важна **первая** ошибка),
   поставить точку останова, пройти отладчиком (`F10` — шаг, `F11` — зайти в функцию).
4. Застрял дольше 30–40 минут → открыть следующую подсказку в карточке или спросить.
5. Коммит: `git add .` → `git commit -m "что сделал"` → отметить шаг здесь.

Логика игры пишется отдельно от вывода на экран — тогда на этапе с графикой её не придётся переписывать.

Материалы:
- <https://ravesli.com/uroki-cpp/> — уроки на русском (перевод learncpp);
- <https://www.learncpp.com> — оригинал, обновляется чаще;
- <https://en.cppreference.com> — справочник (сначала будет казаться сложным — это нормально).

- [ ] `enum class Cell` и `struct Coord`

## Этап 3. Классы: корабль и поле
- [ ] Классы `Ship` и `Board` в отдельных `.h`/`.cpp` в `src/core/`
- [ ] `Board::canPlace` учитывает границы и запрет касания (даже углами)
- [ ] `Board::shoot` возвращает результат: мимо / ранил / убил

Темы: `class`, `public`/`private`, конструкторы, `const`-методы, инкапсуляция, `namespace`, заголовочные файлы.

- [ ] Флот — `std::vector<Ship>`

- [ ] Статистика — `std::map`
- [ ] «Весь флот потоплен» через `std::all_of` с лямбдой

Темы: `vector`, `set`/`unordered_set`, `map`, итераторы, range-for, `<algorithm>`, лямбды.

## Этап 5. Игровой цикл, ООП, случайность
