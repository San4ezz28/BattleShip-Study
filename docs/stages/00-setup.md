# Этап 0. Окружение, сборка, git, отладчик

## Цель

- Проект открыт в VS Code из `D:\My projects\BattleShip_Study`.
- По `F7` собирается, по `Shift+F5` печатает `Hello, Battleship!`.
- Ты умеешь остановить программу на нужной строке отладчиком.
- Ты сделал свой первый коммит и отправил его на GitHub.

## Что прочитать

Уроки на <https://ravesli.com/uroki-cpp/> (в скобках — номер урока в оглавлении, если названия поменялись):

- «Введение в программирование» и «Введение в языки C и C++» — что вообще происходит.
- «Компиляция и линкинг» — что делают компилятор и линкер, откуда берётся `.exe`.
- «Структура программ» — разбор `main()`, `#include`, `std::cout`.
- «Отладка программ: степпинг и точки останова» — **обязательно**.

Git: <https://git-scm.com/book/ru/v2> — главы 1 и 2 («Введение», «Основы Git»). Достаточно понять
`git status`, `git add`, `git commit`, `git push`, `git log`.

## Мини-шаги

1. Установи всё по разделу «Установка окружения» в [README](../../README.md).
2. Склонируй репозиторий и открой папку в VS Code.
3. Выбери Kit (`Visual Studio Build Tools 2022 Release - amd64`), нажми `F7`.
   Внизу в панели Output должно быть `Build finished with exit code 0`.
4. Запусти `Shift+F5`. Увидел `Hello, Battleship!` — отлично.
5. Открой [src/console/main.cpp](../../src/console/main.cpp). Поменяй текст на свой, например
   `Hello, Battleship! Captain: <твоё имя>`. Собери, запусти.
6. Добавь ещё одну строку вывода, например `std::cout << "Ready to play\n";`.
7. **Сломай программу специально**: удали `;` в конце строки и собери.
   Прочитай текст ошибки — в нём есть имя файла и номер строки. Верни `;`.
   Повтори с опечаткой `std::cot` вместо `std::cout`. Привыкай читать ошибки — это основной навык.
8. **Отладчик**: поставь точку останова (красная точка слева от номера строки) на первой строке с `std::cout`.
   Запусти `Ctrl+F5`. Программа остановится. Нажимай `F10` (следующая строка) и смотри, как
   в окне программы появляется текст. `F5` — продолжить до конца.
9. Объяви переменную `int shipsLeft = 10;` и выведи её. Под отладчиком наведи на неё мышь —
   увидишь значение. Посмотри панель **Variables** слева.
10. **Git**: в терминале VS Code (`` Ctrl+` ``):
    ```
    git status
    git add src/console/main.cpp
    git commit -m "Print my own greeting"
    git push
    ```
    Открой репозиторий на GitHub и убедись, что коммит там появился.
11. Отметь пункты этапа 0 в [docs/PLAN.md](../PLAN.md) и закоммить это тоже.

## Про русский текст в консоли

По умолчанию консоль Windows показывает русские буквы «кракозябрами». Самое простое —
пока выводить текст на английском. Если хочется по-русски, добавь в начало `main()`:

```cpp
#include <windows.h>   // в самом верху файла
// ...
SetConsoleOutputCP(CP_UTF8);
SetConsoleCP(CP_UTF8);
```

Флаг `/utf-8` для компилятора уже включён в `CMakeLists.txt`.

## Подсказки

<details>
<summary>Подсказка 1: CMake Tools не видит компилятор / нет нужного Kit</summary>

Скорее всего, при установке Build Tools не была отмечена «Разработка классических приложений на C++».
Запусти Visual Studio Installer ещё раз → «Изменить» → отметь её. Потом в VS Code:
`Ctrl+Shift+P` → `CMake: Scan for Kits`.
</details>

<details>
<summary>Подсказка 2: <code>git push</code> просит логин или пишет «rejected»</summary>

При первом `push` откроется окно входа в GitHub — войди через браузер.
Если пишет `rejected ... fetch first`, значит на GitHub есть коммиты, которых нет у тебя:
выполни `git pull`, потом снова `git push`.
</details>

<details>
<summary>Подсказка 3: точка останова не срабатывает</summary>

Запускать нужно через `Ctrl+F5` (`CMake: Debug`), а не `Shift+F5`. И сборка должна быть Debug
(внизу в строке состояния VS Code написано `Debug`; если `Release` — кликни и переключи).
</details>
